## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 点微信登录没反应 | 小程序产物 appid 是 `touristappid` | 跑 `node scripts/fix-mp-appid.js --src` 重新上传 |
| 提示 invalid code | AppSecret 与 AppID 不配对 | 核对 .env 的 WX_APPID/WX_SECRET |
| 选图报隐私错误 | 公众平台没配《用户隐私保护指引》 | 设置 → 服务内容声明 → 勾选相册/摄像头 |
| 手机连不上后端 | 不是同一网络 / 防火墙 | 同一 WLAN，放行 3000 端口 |
