| 用药条数 | 3 |

**发病症状**

成虫取食甘薯茎叶、叶柄和薯块表皮，造成缺刻和孔洞；幼虫蛀食薯块和茎蔓内部，形成弯曲隧道，隧道内充满虫粪，薯块受害后变黑、发苦、有臭味，不能食用；茎蔓受害后肿大畸形，植株生长衰弱，严重时枯死。

**病因**

甘薯小象甲（Cylas formicarius）成虫和幼虫取食危害，属鞘翅目蚁象甲科，是一种检疫性害虫。

**传播途径**

成虫飞翔力弱，主要通过带虫薯块、薯苗、茎蔓调运远距离传播；田间靠成虫爬行、短距离飞翔扩散；幼虫和蛹随薯块、茎蔓传播。

**发生条件**

南方甘薯区年发生4-6代，世代重叠，以成虫在薯块、茎蔓、田间残株或贮藏窖内越冬；高温干旱年份发生重，沙质土、连作地、管理粗放田块受害重；成虫喜隐蔽，多在清晨和傍晚活动，有假死性。

**推荐用药（前 3 条）**

1. 乐果 40% 乳油 · 中等毒 — 2000倍液 · 浸鲜薯片诱杀（登记证 PD85121-30）
2. 杀螟硫磷 45% 乳油 · 中等毒 — 80-135克/亩 · 浸鲜薯片诱杀（登记证 PD84102-6）
3. 联苯·噻虫嗪 1% 颗粒剂 · 低毒 — 7000-8000克/亩 · 撒施（登记证 PD20181216）

**防治建议（前 3 条）**

   1. 严格检疫，不从疫区调运薯块和薯苗
   2. 选用无虫健康薯苗，栽插前进行药剂浸苗处理
   3. 实行轮作，避免甘薯连作，可与水稻、玉米等轮作

**预防措施（前 3 条）**

   1. 加强植物检疫，严禁带虫薯块、薯苗调运
   2. 建立无虫留种田，培育无虫薯苗
   3. 深耕晒垡，破坏越冬场所，减少虫源

**发病症状**

幼虫取食叶片，初孵幼虫潜叶取食叶肉，形成细小隧道；2龄后啃食叶肉留下表皮，形成透明斑；3-4龄幼虫将叶片吃成孔洞、缺刻，严重时仅留叶脉，呈网状；喜食嫩叶、心叶和幼荚，影响植株生长和结荚。

**病因**

小菜蛾（Plutella xylostella）属鳞翅目菜蛾科，是一种寡食性害虫，主要为害十字花科蔬菜如甘蓝、白菜、花椰菜、萝卜、芥菜等。

**传播途径**

成虫善飞翔，可随风远距离迁飞扩散；卵、幼虫、蛹可随菜苗、蔬菜运输传播；田间世代重叠，繁殖速度快，在适宜温度下短时间内可暴发成灾。

**发生条件**

年发生代数因地区而异，北方3-6代，南方可达10代以上，世代重叠明显；适宜温度20-30℃，高温干旱利于发生；春秋两季为发生高峰；成虫昼伏夜出，有趋光性；幼虫活泼，受惊吐丝下垂；在十字花科蔬菜连作、管理粗放的田块发生重。

**推荐用药（前 3 条）**

1. 高效氯氰菊酯 4.5% 乳油 · 中等毒 — 15-40毫升/亩 · 喷雾（登记证 PD20060134）
2. 苏云金杆菌 8000IU/毫克 可湿性粉剂 · 低毒 — 50-100克/亩 · 喷雾（登记证 PD20094822）
3. 氯菊酯 10% 乳油 · 低毒 — 4000-10000倍液 · 喷雾（登记证 PD86138）

**防治建议（前 3 条）**

   1. 坚持预防为主、综合防治，优先采用农业防治和生物防治
   2. 在低龄幼虫期（1-2龄）及时用药，效果最佳
   3. 药剂交替轮换使用，避免长期单一用药导致抗药性

**预防措施（前 3 条）**

   1. 合理轮作，避免十字花科蔬菜连作，减少虫源积累
   2. 清洁田园，及时清除残株落叶和杂草，深翻晒垡
   3. 覆盖防虫网或地膜，阻隔成虫产卵和幼虫为害

| 配图 | 无 |
| 用药条数 | 3 |

**发病症状**

主要危害嫩梢、花穗、果实和叶片。叶片受害初期出现褐色小斑，后扩大为不规则黄褐色至暗褐色病斑，湿度大时病斑背面产生白色霜状霉层；花穗受害变褐腐烂，表面生白色霉层，导致落花；果实受害多从果蒂开始，果皮变褐、软腐，表面生白色至淡黄色霜状霉层，严重时大量落果，有酸腐味。

**病因**

由荔枝霜疫霉（Peronophythora litchii）侵染引起，属卵菌门霜疫霉属，是一种专性寄生性较强的病原菌，喜高温高湿环境。

**传播途径**

病菌以卵孢子或菌丝体在病果、病叶、病枝及土壤中越冬；翌年产生孢子囊，借风雨、气流传播，也可通过带病苗木、果实调运远距离传播；孢子囊萌发产生游动孢子，从气孔、伤口或直接穿透表皮侵入。

**发生条件**

发病与温湿度关系密切，高温高湿、多雨季节易流行，尤其花期和果实成熟期遇连续阴雨、雾大露重时发病重；果园郁闭、通风透光差、地势低洼积水、偏施氮肥的果园发病较重；不同品种抗性有差异，一般早熟品种和果皮薄品种较感病。

**推荐用药（前 3 条）**

1. 氧化亚铜 86.2% 水分散粒剂 · 低毒 — 1000-1500倍液 · 喷雾（登记证 PD20110480）
2. 乙铝·代森锌 70% 水分散粒剂 · 低毒 — 600-800倍液 · 喷雾（登记证 PD20151038）
3. 氟吗·乙铝 50% 水分散粒剂 · 低毒 — 625-833倍液 · 喷雾（登记证 PD20095462）

**防治建议（前 3 条）**

   1. 加强果园巡查，发现病果、病穗及时摘除并集中销毁，减少侵染源
   2. 花期和幼果期遇阴雨天气应抢晴喷药保护，重点喷施花穗和果穗
   3. 药剂应交替使用，避免长期单一用药产生抗药性

**预防措施（前 3 条）**

   1. 选用抗病性较强的品种，合理密植，避免过密栽植
   2. 加强栽培管理，增施有机肥和磷钾肥，避免偏施氮肥，提高树体抗病力
   3. 冬季清园，剪除病枝、病叶，清除落果和枯枝落叶，集中烧毁或深埋

**发病症状**

幼虫钻蛀水稻茎秆，造成枯心苗、枯孕穗、白穗和虫伤株；分蘖期受害形成枯心，孕穗抽穗期受害形成白穗或半白穗，茎秆内可见虫粪和蛀孔。

**病因**

二化螟（Chilo suppressalis）幼虫蛀食水稻等禾本科作物茎秆，破坏输导组织，导致水分养分运输受阻而枯死或形成白穗。

**传播途径**

以幼虫在稻桩、稻草、茭白等寄主残体中越冬，翌年化蛹羽化为成虫，成虫具趋光性，夜间交配产卵于稻叶背面或叶鞘上，孵化幼虫爬行或吐丝下垂扩散，转株危害。

**发生条件**

一年发生2～4代，随纬度升高代数减少；越冬幼虫在春季气温回升后化蛹，成虫盛发期多在5～7月；高温高湿、田间郁闭、偏施氮肥、稻桩稻草残留多的田块发生重；幼虫有转株危害习性。

**推荐用药（前 3 条）**

1. 三唑磷 20% 乳油 · 中等毒 — 150-200毫升/亩 · 喷雾（登记证 PD20120069）
2. 马拉·三唑磷 25% 乳油 · 中等毒 — 75-100毫升/亩 · 喷雾（登记证 PD20070005）
3. 阿维·三唑磷 20% 乳油 · 中等毒(原药高毒) — 50-70毫升/亩 · 喷雾（登记证 PD20111430）

**防治建议（前 3 条）**

   1. 在卵孵盛期至低龄幼虫钻蛀前施药，效果最佳，避免高龄幼虫钻入茎秆后防治困难
   2. 交替轮换使用不同作用机理药剂，延缓抗药性产生
   3. 施药时保持田间浅水层3～5厘米，提高药效

**预防措施（前 3 条）**

   1. 冬季清除田间稻桩、稻草和茭白残体，集中销毁或沤肥，减少越冬虫源
   2. 春季灌水泡田灭蛹，降低越冬代羽化率
   3. 合理密植，避免偏施氮肥，增施磷钾肥，增强植株抗性

| 项 | 内容 |

**发病症状**

蛴螬为金龟子幼虫，栖居土中啃食植物地下部分。直接咬断或啃伤幼苗根茎，造成缺苗断垄；主根、侧根被蛀食后植株矮小、叶片发黄萎蔫，严重时整株枯死。块根、块茎类作物被蛀成孔洞，降低产量和品质。草坪、苗木受害后根系受损，出现成片枯死斑。

**病因**

蛴螬是鞘翅目金龟甲总科幼虫的统称，常见有大黑鳃金龟、暗黑鳃金龟、铜绿丽金龟等。以幼虫在土壤中越冬并危害，成虫金龟子取食叶片、花器。发生轻重与土壤有机质含量、未腐熟有机肥施用、前茬作物及土壤温湿度密切相关。

**传播途径**

成虫金龟子具飞翔能力，可迁飞扩散并选择适宜产卵场所；幼虫随土壤、苗木、种苗及未腐熟农家肥调运传播。田间主要通过成虫产卵于疏松湿润、富含有机质的土壤中而扩大发生范围。

**发生条件**

一年发生1代或2代，以幼虫或成虫在土中越冬。春季土温回升后幼虫上移危害，夏季化蛹羽化，成虫夜间活动、趋光性强，产卵于土中。土壤湿润、有机质丰富、施用未腐熟粪肥的地块发生重；沙壤土、连作地块虫口密度较高。

**推荐用药（前 3 条）**

1. 噻虫嗪 0.12% 颗粒剂 · 低毒 — 30-40千克/亩 · 撒施（登记证 PD20212446）
2. 噻虫胺 0.1% 颗粒剂 · 微毒 — 30-50千克/亩 · 撒施（登记证 PD20264496）
3. 二嗪磷 0.1% 颗粒剂 · 低毒 — 40-50千克/亩 · 撒施（登记证 PD20211068）

**防治建议（前 3 条）**

   1. 播种或移栽前进行土壤处理，结合整地施用毒土或颗粒剂
   2. 发现幼虫危害时及时用辛硫磷、毒死蜱等药剂灌根，重点浇灌根际土壤
   3. 成虫盛发期利用黑光灯、糖醋液诱杀金龟子，减少产卵量

**预防措施（前 3 条）**

   1. 施用充分腐熟的有机肥，避免将幼虫和卵带入田间
   2. 秋季深翻土壤，破坏蛴螬越冬环境，降低越冬虫口基数
   3. 清除田间及周边杂草、残株，减少成虫栖息和产卵场所

| 数据来源 | 农业农村部 NY/T《农作物病虫害监测数据规范》名录（编码 1002203） |
| 配图 | 无 |
| 用药条数 | 0 |

**发病症状**

主要危害花、幼果、叶片和茎蔓。花器染病初呈水渍状，后变软腐烂，表面密生灰褐色霉层，常引起落花。幼果受害多从残花处开始，初呈水渍状软腐，后扩展至整个果实，表面产生大量灰褐色霉层，病果脱落或干缩。叶片染病多从叶缘或叶尖开始，初为水渍状小斑点，后扩大为褐色至灰褐色不规则病斑，边缘不明显，潮湿时病斑上长出灰色霉层。茎蔓染病呈水渍状褐色病斑，绕茎扩展后致茎蔓腐烂、折断，病部以上枝叶萎蔫枯死。

**病因**

由灰葡萄孢菌（Botrytis cinerea）侵染引起，属半知菌亚门真菌。病菌喜低温高湿环境，发育适温15～23℃，相对湿度90%以上易发病。分生孢子梗丛生，顶端分枝，着生大量分生孢子，孢子梗和孢子呈灰褐色。病菌寄主范围广，可侵染多种蔬菜和花卉。

**传播途径**

病菌以菌核、菌丝体或分生孢子在土壤中、病残体上越冬，也可在棚室支架、薄膜上存活。分生孢子借气流、雨水、灌溉水及农事操作传播，从伤口、衰老组织或花器侵入。田间病株上的病菌可多次再侵染，造成病害流行。

**发生条件**

低温高湿是发病的关键因素，棚室栽培在冬春季节、连阴雨天气、通风不良、湿度大时发病重。植株密度过大、氮肥偏多、植株徒长、伤口多、花期遇低温阴雨易诱发。保护地栽培比露地栽培发生重，连作地块、病残体清理不彻底的地块发病早且重。

**推荐用药（前 3 条）**

（无用药方案）

**防治建议（前 3 条）**

   1. 发病初期及时摘除病花、病果、病叶，带出田外深埋或销毁，减少再侵染源
   2. 药剂防治注意交替轮换使用不同作用机理的药剂，避免病菌产生抗药性
   3. 棚室栽培优先采用烟剂或粉尘剂防治，减少喷雾增加湿度

主要危害叶片，也可侵染叶柄、茎和块茎。叶片发病初期出现水渍状暗褐色小斑点，后扩大为近圆形或不规则形褐色病斑，具明显同心轮纹，外围有黄色晕圈；湿度大时病斑上生黑色霉层。严重时病斑连片，叶片枯黄脱落。块茎受害形成暗褐色凹陷病斑，边缘清晰，病部皮下组织呈褐色干腐。

病菌以菌丝体和分生孢子在病残体、病薯及土壤中越冬，成为翌年初侵染源。田间主要靠分生孢子借风雨、气流传播，进行多次再侵染；农事操作、灌溉水也可传播。带病种薯可远距离传播。

**发生条件**

一般现蕾至开花期开始发病，块茎膨大期进入发病盛期。高温多雨、昼夜温差大、结露时间长时发病重；连作、密度过大、通风透光差、土壤瘠薄或偏施氮肥的地块发病早而重。长江流域及南方春马铃薯多在5～6月流行，北方夏秋马铃薯在7～8月流行。

**推荐用药（前 3 条）**

1. 吡唑醚菌酯 30% 乳油 · 低毒 — 30-40毫升/亩 · 喷雾（登记证 PD20211986）
2. 苯甲·嘧菌酯 30% 悬浮剂 · 低毒 — 40-50毫升/亩 · 喷雾（登记证 PD20211913）
3. 啶氧·丙环唑 19% 微乳剂 · 低毒 — 42.5-50毫升/亩 · 喷雾（登记证 PD20211418）

   2. 发病初期及时用药，注意轮换用药以延缓抗药性
   3. 合理密植，改善田间通风透光条件，降低田间湿度
