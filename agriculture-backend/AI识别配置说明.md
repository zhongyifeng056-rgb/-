# AI 识别功能 · 配置与使用说明

> 后端位置：`agriculture-backend/`　相关文件：`routes/disease.js`、`app.js`、`.env.example`

---

## 一、这个识别功能现在是什么状态

流程已经通了，但**必须配置密钥才是真实 AI 识别**。启动后端时会打印当前状态：

| 打印内容 | 含义 |
|---|---|
| `🤖 AI 识别状态：DeepSeek + 百度植物识别（真实 AI 识别）` | 最佳，两家都配了 |
| `🤖 AI 识别状态：仅 DeepSeek（用大模型识图 + 判断病害）` | 够用，只配 DeepSeek 即可 |
| `🤖 AI 识别状态：仅百度植物识别（病害按本地库匹配）` | 能识别植物，病害靠本地库猜 |
| `🤖 AI 识别状态：未配置密钥 —— 识别会退化为「本地模拟」` | 结果不准确，仅能演示 |

## 二、第一步：申请 DeepSeek 密钥（推荐先弄这个，最省事）

DeepSeek 的 `deepseek-flash` 模型**既能看图又能判断病害**，只配它一家就能跑通全流程。

1. 打开 <https://platform.deepseek.com> 注册并登录
2. 左侧菜单 **API Keys** → **创建 API Key**，起个名字（如 `SL识别`）
3. **马上复制**弹出的那串 `sk-xxxxxxxx`（关掉就再也看不到，只能重建）
4. 左侧 **充值 / Top up**，充 **10 元**（够用很久，单次识别成本不到 1 分钱）

## 三、第二步（可选）：申请百度植物识别

百度植物识别的植物种类库更专业，配了可以「百度识别植物 + DeepSeek 判断病害」，准确率更高。
**只配 DeepSeek 也完全能用**，这步可以先跳过。

1. 打开 <https://console.bce.baidu.com/>，注册并完成实名认证
2. 顶部搜索 **图像识别**，进入产品页，点 **立即使用 / 创建应用**
3. 应用里勾选 **植物识别**，创建完成后在应用详情页能看到：
   - **API Key**（就是 `BAIDU_API_KEY`）
   - **Secret Key**（就是 `BAIDU_SECRET_KEY`）
4. 免费额度用完后按量付费，约 **0.002 元/次**，学生用基本在免费额度内

## 四、第三步：把密钥填进 .env

在 `agriculture-backend` 目录里：

1. 把 `.env.example` **复制一份，改名为 `.env`**（注意开头有个点，Windows 里改名成 `.env` 即可）
2. 用记事本打开 `.env`，把等号后面填上自己的值：

```
PORT=3000

# DeepSeek（必须）
DEEPSEEK_API_KEY=sk-你复制到的那串

# 百度（可选，不申请就留空）
BAIDU_API_KEY=
BAIDU_SECRET_KEY=
```

3. 保存，**重启后端**（在命令行窗口按 `Ctrl + C`，再执行 `node app.js`）

> `.env` 已加入 `.gitignore`，不会被提交，密钥不会外泄。
> 复制 `.env.example` 而不是直接把密钥写进代码 —— 代码里永远不出现密钥。

## 五、第四步：验证

1. 后端启动日志里应显示 `🤖 AI 识别状态：...（真实 AI 识别）`
2. H5 页面进入「识别」页，拍照或选图
3. 识别期间看**后端控制台**，会依次打印：
   ```
   🔍 百度植物识别中...
   🌿 百度识别：柑橘 (93%)
   🧠 DeepSeek 识图中...
   🧠 DeepSeek：柑橘 → 柑橘溃疡病 (88%)
   ✅ 识别完成：柑橘 → 柑橘溃疡病 (88%) [百度植物识别 + DeepSeek 诊断]
   ```
4. 结果卡片上应显示**置信度**和**病害名**，不是每次都不一样

## 六、三种模式说明

| 模式 | 触发条件 | 结果 |
|---|---|---|
| **真实识别（双通道）** | 配了百度 + DeepSeek | 百度识别植物 → DeepSeek 看图和判断病害 → 匹配本地防治方案 |
| **真实识别（单通道）** | 只配 DeepSeek | DeepSeek 直接看图，识别植物并判断病害 → 匹配本地防治方案 |
| **本地模拟** | 没配密钥 | 按图片特征从本地库固定取一条，**同一张图结果固定、不再乱跳**；页面会提示"本地模拟" |

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| 启动日志显示"未配置密钥" | `.env` 没建、名字不对（比如存成了 `.env.txt`）、或没重启后端 |
| 打印 `DeepSeek 识图失败：401` | API Key 错或没充值 |
| 打印 `DeepSeek 识图失败：... 402` | 余额不足，去充值 |
| 打印 `百度植物识别失败：invalid client_id` | 百度应用没勾选「植物识别」权限，或 Key 填错 |
| 打印 `百度植物识别失败：... quota` | 百度免费额度用完，可忽略（会自动走 DeepSeek） |
| 提示"本地知识库没有匹配到该病害" | AI 判断的病害名不在本地库中，防治方案为 AI 给的通用建议 |
| 拍照按钮没反应（手机 App） | 需要相机权限；H5 浏览器端用「从相册选择」 |

## 八、关于费用

- 一次识别约消耗 1000 输入 token + 400 输出 token
- DeepSeek Flash 价格：输出约 1.2 元/百万 token（高峰）
- **单次识别成本约 0.001～0.003 元**，10 元够跑几千次
- 百度植物识别在免费额度内为 0 元
