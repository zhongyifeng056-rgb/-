# 后端接口文档

> 位置：`agriculture-backend/`　统一返回格式：`{ code, message, data }`，`code: 200` 表示成功
> 需要登录的接口请在请求头带上：`Authorization: Bearer <token>`

## 通用

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查。返回服务时间、数据库状态、AI 密钥是否配置。**前端用它探测后端地址** |
| GET | `/` | 服务首页提示 |
| GET | `/uploads/*` | 静态图片（上传的识别图、头像） |

## 用户 `/api/user`

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| POST | `/register` | - | 注册。账号 4~20 位、密码 6~64 位 |
| POST | `/login` | - | 登录，返回 `token` 与 `userInfo`（含 `nickname` / `avatar` / `isAdmin`） |
| GET | `/info` | ✔ | 当前用户信息 |
| POST | `/profile` | ✔ | 修改昵称与头像 |
| POST | `/logout` | ✔ | 退出登录 |
| POST | `/feedback` | ✔ | 提交意见反馈 |

## 病虫害 `/api/disease`

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/diseases/list` | - | 病虫害列表，支持 `page` `pageSize` `keyword` |
| GET | `/detail?id=` | - | 病虫害详情（含症状/用药/防治方案） |
| POST | `/recognize` | 可选 | **AI 识别**（上传字段名 `image`）。百度植物识别 + DeepSeek 诊断，限流 8 次/分钟 |
| POST | `/upload` | 可选 | 通用图片上传（头像用）。返回 `{ url }`，限流 10 次/分钟 |
| POST | `/correct` | 可选 | **用户纠错**：提交正确病害名，修正历史记录并收录知识库（自动生成防治方案）。限流 5 次/分钟 |

## 识别历史 `/api/history`（均需登录）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/add` | 新增记录 |
| GET | `/list` | 列表，支持 `page` `pageSize`（默认 50，上限 200） |
| POST | `/delete` | 删除单条（**只能删自己的**） |
| POST | `/clear` | 清空自己的记录，返回删除条数 |

## 收藏 `/api/collection`（均需登录）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/add` | 收藏（重复收藏会被拒） |
| GET | `/list` | 列表，支持分页 |
| POST | `/delete` | 取消收藏，可传 `id`（收藏记录 id）或 `disease_id`（**只能删自己的**） |

## 预警与统计

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/api/warning/list` | - | 病虫害预警列表 |
| GET | `/api/stats/summary` | 可选 | 全局统计；**带 token 时额外返回** `myHistoryCount` `myCollectionCount` 与最近 7 天识别趋势 `trend` |
| GET | `/api/stats/hot?limit=8` | - | 识别次数最多的病害排行 |

## 管理后台（网页版，浏览器访问）

地址：`http://<后端地址>:3000/admin`　**仅 `is_admin = 1` 的账号可登录**（默认 admin / 123456）
界面样式为本地文件（`public/admin.css`），不依赖外网 CDN，断网也能正常显示。

| 页面 | 路径 | 能做什么 |
|---|---|---|
| 登录 | `/admin/login` | 管理员登录（只认数据库中的管理员账号） |
| 数据概览 | `/admin` | 统计卡、最近 7 天趋势图、病害 TOP8、最新记录、系统状态（数据库/AI 密钥） |
| 用户管理 | `/admin/users` | 搜索、分页；**查看每个用户的识别/收藏数量** |
| 用户详情 | `/admin/users/:id` | 查看资料与该用户的识别记录/收藏/纠错；**修改昵称与管理员权限、重置密码、清空其识别记录、删除用户**（连带清理数据） |
| 识别历史 | `/admin/histories` | 搜索、只看已纠正、分页；**单条删除 / 勾选批量删除 / 导出 CSV**（带 BOM，Excel 不乱码） |
| 病虫害库 | `/admin/diseases` | 搜索分页、新增、编辑、删除；**新增/编辑页有「✨ AI 自动生成资料」按钮**，填个病名就能自动补全症状/病因/用药等 |
| 用户纠错 | `/admin/corrections` | 查看「AI 原判断 vs 用户正确答案」，可删除记录 |

**后台安全约束**：不能删除当前登录账号、不能删除或降级最后一个管理员。

## 安全设计

- 密码使用 **bcrypt** 哈希存储，登录返回 **JWT**（有效期 7 天）
- 历史/收藏的删除操作**强制校验归属**，无法操作他人数据
- 后台登录**只认数据库中的管理员账号**，无硬编码后门；后台注册接口也需管理员权限
- AI 相关接口有**限流**，防止被刷导致费用失控
- 上传文件做**真实大小校验**，异常文件统一返回 JSON 错误
- 后台用户管理有**安全约束**：不能删除自己、不能删掉/降级最后一个管理员
