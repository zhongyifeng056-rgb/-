# 上线部署指南

> 目标：让**任何人用网址或手机**就能使用你的系统
> 架构：一台云服务器上跑「后端 API + H5 网页 + 管理后台」，数据存 SQLite 文件

---

## 一、先搞清楚要买什么

### 推荐配置（毕业设计 / 课程项目完全够用）

| 项目 | 推荐 | 说明 |
|---|---|---|
| CPU / 内存 | **2 核 2G** | 1 核 1G 也能跑，但装依赖时容易失败 |
| 硬盘 | 40G 系统盘 | 你的项目不到 20MB |
| 带宽 | **3M 以上** | 1M 打开网页会明显慢 |
| 系统 | **Ubuntu 22.04** | 教程最多，出问题好搜 |
| 地域 | 见下方「要不要备案」 | |

### 国内云厂商（学生有优惠）

| 厂商 | 产品 | 大致价格 | 备注 |
|---|---|---|---|
| 阿里云 | 轻量应用服务器 | 学生认证后约 **9.9~38 元/月** | 搜「阿里云高校计划」 |
| 腾讯云 | 轻量应用服务器 | 学生约 **10~30 元/月** | 搜「腾讯云学生机」 |
| 华为云 | 云耀服务器 | 学生约 **10~40 元/月** | |

> 买之前一定先领学生优惠（需学生认证），能便宜一大半。

### ⚠️ 关键决策：要不要备案？

| 你的情况 | 建议 | 后果 |
|---|---|---|
| 只做答辩 / 演示，**不申请域名** | 买**国内**服务器，直接用 **IP 访问** | 不用备案，最省事 |
| 想要正式域名 | 国内服务器**必须 ICP 备案**（免费，7~20 天） | 想快就用**香港/新加坡**节点，免备案，但延迟略高 |
| 要发布**微信小程序** | **必须 HTTPS + 已备案域名** | 小程序不允许用 IP，也不允许 http |

**最省事的路线**：先买国内学生机 → 用 IP 直接访问（http://你的IP）→ 答辩够用。确定长期用再买域名备案。

### ❌ 不要选的方案（踩坑提醒）

- **Vercel / Netlify / GitHub Pages**：只能放静态网页，你的后端要写 SQLite、要上传图片，**放不了**
- **免费虚拟主机 / 免费容器**：多数不支持 Node + 持久化文件，数据库会被清空
- **1 核 512M 内存**：装 sqlite3 依赖时经常编译失败

## 二、买完服务器第一件事：开端口

在云厂商控制台找到「**安全组 / 防火墙**」，放行：

| 端口 | 用途 | 是否必须 |
|---|---|---|
| 22 | SSH 远程连接 | 必须 |
| 80 | HTTP 网页访问 | 必须 |
| 443 | HTTPS | 有域名时才需要 |
| 3000 | 后端 API 直连 | 建议只在内网用，配好 Nginx 后可关闭 |

> 很多「部署后打不开」都是**忘了开安全组**。

## 三、服务器环境准备（复制粘贴即可）

用 SSH 连上服务器（Windows 可用 FinalShell / Xshell，或系统自带的 ssh 命令）。

第一步：更新系统并安装 Node 20

    sudo apt update && sudo apt upgrade -y
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
    source ~/.bashrc
    nvm install 20 && nvm use 20
    node -v      # 应显示 v20.x

第二步：安装 PM2（进程守护，崩溃自动重启）

    npm install -g pm2

第三步：安装 Nginx（反向代理 + 托管网页）

    sudo apt install nginx -y
    sudo systemctl enable nginx

## 五、配置并启动后端

### 1. 创建 .env（密钥不写进代码）

    cd /www/agriculture-backend
    cp .env.example .env
    nano .env

填入真实配置：

    NODE_ENV=production
    PORT=3000
    DEEPSEEK_API_KEY=sk-你的密钥
    BAIDU_API_KEY=你的百度Key
    BAIDU_SECRET_KEY=你的百度Secret
    SESSION_SECRET=随便敲一串32位随机字符

保存：Ctrl+O → 回车 → Ctrl+X

### 2. 用 PM2 启动

    pm2 start ecosystem.config.js --env production
    pm2 save        # 保存进程列表
    pm2 startup     # 生成开机自启命令，按提示复制执行一次
    pm2 logs agr-backend    # 看日志

启动成功的日志应该长这样：

    ✅ 数据库初始化成功
    ✅ 服务运行：http://localhost:3000
    🚀 运行模式：生产环境（已启用压缩/安全头/访问日志）
    🤖 AI 识别状态：DeepSeek + 百度植物识别（真实 AI 识别）

服务器上自测：`curl http://localhost:3000/api/health`

### 3. 迁移数据（把本地数据带上去）

    scp "C:\Users\24886\Documents\HBuilderProjects\SL\agriculture-backend\agriculture.db" root@你的IP:/www/agriculture-backend/
    scp -r "C:\Users\24886\Documents\HBuilderProjects\SL\agriculture-backend\public\uploads" root@你的IP:/www/agriculture-backend/public/

传完执行 `pm2 restart agr-backend`。

## 六、编译并部署 H5 网页

### 1. 本地编译

在 HBuilderX 里：**发行 → 网站-PC Web 或手机 H5 → 填写站点标题 → 发行**

产物生成在项目的 `unpackage/dist/build/h5` 目录。

> 前端地址会自动用「当前网页地址」，**部署后不用改任何 IP**——这正是之前把它做成自动探测的好处。

### 2. 上传到服务器

    scp -r "C:\Users\24886\Documents\HBuilderProjects\SL\unpackage\dist\build\h5\*" root@你的IP:/www/h5/

### 3. 配置 Nginx（同时托管网页并转发接口）

执行 `sudo nano /etc/nginx/sites-available/agr`，粘贴以下内容（把「你的IP」换成实际 IP 或域名）：

    server {
        listen 80;
        server_name 你的IP;

        root /www/h5;
        index index.html;

        location / {
            try_files $uri $uri/ /index.html;
        }

        location /api/ {
            proxy_pass http://127.0.0.1:3000;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            client_max_body_size 10m;
        }

        location /uploads/ {
            proxy_pass http://127.0.0.1:3000;
        }

        location /admin {
            proxy_pass http://127.0.0.1:3000;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }

        location = /admin.css {
            proxy_pass http://127.0.0.1:3000;
        }
    }

启用并重载：

    sudo ln -s /etc/nginx/sites-available/agr /etc/nginx/sites-enabled/
    sudo rm -f /etc/nginx/sites-enabled/default
    sudo nginx -t && sudo systemctl reload nginx

现在浏览器打开 http://你的IP 就能看到 App，http://你的IP/admin 是管理后台。

## 七、（可选）配域名和 HTTPS

1. 域名解析到服务器 IP（A 记录）
2. 国内服务器需先完成 **ICP 备案**（免费，7~20 天）
3. 申请免费证书并自动配置：

    sudo apt install certbot python3-certbot-nginx -y
    sudo certbot --nginx -d 你的域名.com

配好 HTTPS 后建议收紧跨域（编辑 .env）：

    CORS_ORIGIN=https://你的域名.com

然后 `pm2 restart agr-backend`。

## 八、打包安卓 App（可选）

后端部署好后，App 里需要改**一处**地址：打开项目 `utils/config.js`，把 APP_BASE_URL 改成服务器地址：

    export const APP_BASE_URL = 'http://你的服务器IP:3000'

> H5 会自动用当前网页地址，**只有打包成 App 才需要改这里**。

然后 HBuilderX：**发行 → 原生App-云打包 → Android → 使用公共测试证书** → 打包下载 APK 安装。

## 九、常见问题排查

| 现象 | 原因与解决 |
|---|---|
| 浏览器打不开网页 | ① 安全组没放行 80 ② Nginx 没启动：`sudo systemctl status nginx` |
| 网页能开但接口 502 | 后端没跑起来：`pm2 status` / `pm2 logs agr-backend` |
| 接口报 CORS 错误 | 检查 .env 的 CORS_ORIGIN 是否写对（多个用英文逗号） |
| 上传图片失败 | Nginx 缺 `client_max_body_size 10m` |
| npm install 卡在 sqlite3 | 内存不足，加 swap：`sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile` |
| 重启服务器后网站打不开 | 没执行 `pm2 startup` + `pm2 save` |
| 管理后台打不开 | Nginx 里 /admin 与 /admin.css 两处都要转发 |
| AI 识别报「未配置密钥」 | 服务器 .env 没填密钥，或填完没 `pm2 restart` |

### 日常运维命令

    pm2 status                  # 运行状态
    pm2 logs agr-backend        # 实时日志
    pm2 restart agr-backend     # 改完代码后重启
    pm2 monit                   # 监控 CPU / 内存

    # 备份数据库（建议加进 crontab 每天自动备份）
    cp /www/agriculture-backend/agriculture.db ~/backup-$(date +%F).db
